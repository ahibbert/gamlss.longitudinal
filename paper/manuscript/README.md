# JSS Manuscript Source

This directory is the staging area for the JSS-style manuscript source.

Start from `jss-skeleton.tex`, then replace each placeholder with final text
from `paper/jss-manuscript-blueprint.md`. Keep the manuscript synchronized with:

- `paper/jss-submission-audit.csv` for figure/table placement decisions.
- `paper/manifest.csv` for reproducible output IDs and paths.
- `paper/jss-submission-checklist.md` for submission gates.

Do not make private-data analyses the primary worked example unless reviewers
will receive accepted data access instructions.
