Overview of Support Articles

Welcome to the support page for gamlss_longitudinal !

This package provides a easy to use for fitting longitudinal regression models with gamlss margins and copulas for dependence.

This page is organised around your use case. In ‘Start Here’ we provide a basic workflow (which you can apply directly to your own dataset) and a more detailed worked example which uses a simulated dataset using the built in simulation features. The following sections provide more detail for each of the components of the workflow.

Please report any bugs or issues on our github at https://github.com/ahibbert/gamlss.longitudinal/issues or feel free to reach out to the maintainer at a.d.hibbert@gmail.com for any clarifications.

This work is largely based on published research by Aydin Sareff-Hibbert and Gillian Heller: https://arxiv.org/abs/2410.11892 https://arxiv.org/abs/2410.11892 (update to gamlss_longitudinal paper)
